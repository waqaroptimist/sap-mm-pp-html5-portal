Configuration & Troubleshooting Runbooks

Expand each operational step below for configuration paths and verification checks (built with native HTML5 <details> elements—zero JavaScript required).

1. Material Type Setup via OMS2

Navigate to SPRO → Logistics - General → Material Master → Basic Settings → Material Types → Define Attributes of Material Types.

  • Verify Quantity Updating and Value Updating per Valuation Area.
  • Assign appropriate Field Selection Group and Account Category Reference.
2. Contract Release Strategy Verification (ME31K)

Ensure contract document types (MK for Quantity Contract, WK for Value Contract) are linked to active release classes and target value thresholds.

Table Check (SE16N):
EKKO-BSTYP = 'K'  (Purchasing Document Category: Contract)
EKKO-BSART = 'MK' (Document Type: Quantity Contract)
3. Pre-MRP Run Readiness Checklist (MD02)
  1. Confirm open Purchase Requisitions and Planned Orders are up to date.
  2. Validate BOM (CS03) and Routing (CA03) validity dates.
  3. Check stock levels in restricted vs. unrestricted-use storage locations.

Quick ERP Glossary

MRP (Material Requirements Planning)
Automated planning process that calculates net material shortages and generates procurement proposals.
ME31K
Transaction used to establish long-term vendor contracts before issuing release purchase orders.
SPRO
SAP Project Reference Object; the central configuration menu for customizing SAP modules.
